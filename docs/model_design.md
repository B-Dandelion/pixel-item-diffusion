# U-Net / DDPM 설계 초안

2026-11-18. 현재 구현은 **클래스 무조건부 RGB 초안**이다. 조건부 생성은 사용자에게 허용 가능한 선택지이며 필수 모델이라는 뜻이 아니다. 최종 데이터, RGB/RGBA, 클래스 사용 여부, 수업에서 허용된 세부 연산을 확인한 후 확정한다. 본 학습은 실행하지 않았다.

사용자 목표 화풍은 **Idylwild Inventory와 유사하며 채도는 아주 조금 높은 방향**이다. 이는 수집·선별 기준이며 원본 색상 변환이나 색상 증강을 승인된 최종 전처리로 확정한 것이 아니다. 현재 색상 변환은 적용하지 않았다. 본 학습용 이미지 목표는 정제·검증셋 분리 후 5,000장 이상이다. `base.json`의 관련 항목은 목표 메타데이터이며 현재 학습 코드가 이 최소 수량을 강제 검증하지는 않는다.

## 네트워크와 형태

`src/unet.py`: 직접 작성한 합성곱 U-Net. Attention과 사전학습 가중치 없음. 표의 C는 설계상 3 또는 4이나 현재 데이터로더·설정 검증·PNG 저장은 RGB(C=3)만 지원한다.

| 단계 | 출력 Tensor (B, 채널, 높이, 너비) | 연산 |
|---|---|---|
| 입력 | B,C,32,32 | 잡음이 섞인 이미지 x_t |
| 입력 합성곱·encoder32 | B,64,32,32 | 3×3 Conv, residual block; skip32 보관 |
| down16·encoder16 | B,128,16,16 | 4×4 stride 2 Conv, residual block; skip16 보관 |
| down8·middle ×2 | B,256,8,8 | 4×4 stride 2 Conv, residual block ×2 |
| up16·skip 결합 | B,256,16,16 | nearest 업샘플·3×3 Conv로 128채널, skip16과 concat |
| decoder16 | B,128,16,16 | residual block |
| up32·skip 결합 | B,128,32,32 | nearest 업샘플·3×3 Conv로 64채널, skip32와 concat |
| decoder32·출력 | B,C,32,32 | residual block, GroupNorm·SiLU·3×3 Conv |

각 residual block은 정규화·활성화·합성곱, 시간 임베딩 가산, 정규화·활성화·합성곱과 잔차 경로로 구성된다. timestep t의 sinusoidal embedding 64차원 → MLP 256차원 → 각 블록 채널로 투영한다. 작은 이미지의 국소 경계와 전체 형태를 함께 보며 동일 해상도 skip으로 세부 정보를 전달한다. 32→16→8의 3단계는 초기 비교안이며 품질 우수성이 검증된 구조라는 뜻은 아니다.

클래스 조건부를 선택한다면 정수 클래스 y의 학습 가능한 임베딩을 시간 임베딩에 더하는 방식을 검토한다. Attention은 필요하지 않다. 하지만 이 연산의 수업 범위 확인, 수동 검토된 클래스 매핑, 데이터로더·샘플러·체크포인트 변경이 필요하다. 현재 구현에는 클래스 임베딩과 조건 입력이 없다. 클래스 수와 조건부 도입을 아직 정하지 않았다.

## 확산과 역확산

`src/diffusion.py`는 epsilon prediction DDPM 초안이다. 배열 인덱스 t=0은 첫 번째 잡음 단계이며, 그때 역과정의 추가 잡음 분산은 0이다.

```text
beta_t: 0.0001 → 0.02 선형, T=1000 (초기 후보)
alpha_t = 1 - beta_t
alpha_bar_t = product(alpha_s, s<=t)
x_t = sqrt(alpha_bar_t) x_0 + sqrt(1-alpha_bar_t) epsilon
t ~ Uniform({0,...,T-1}), epsilon ~ N(0,I)
loss = mean((epsilon_theta(x_t,t) - epsilon)^2)
```

역과정은 예측 epsilon으로 x_0를 추정하고 [-1,1]로 제한한 뒤, q(x_{t-1}|x_t,x_0)의 평균과 posterior variance로 한 단계씩 샘플링한다. posterior variance는 `beta_t*(1-alpha_bar_previous)/(1-alpha_bar_t)`이며 첫 단계의 previous alpha_bar는 1이다. 마지막 역단계는 잡음을 더하지 않는다. 시작은 표준정규 잡음이다. T=1000의 계산비용과 품질은 실제 샘플링 후 평가해야 한다.

## 전처리 제안과 결정 상태

현재 검토 대상의 원본 보존과 출처별 분리를 유지한다. 사용자 요청으로 미사용 자료는 삭제했고, Pixel-art 172K와 Krea 16은 합성 학습 후보로 재검토한다. PixelGPT는 제외한다. 아래 학습 변환은 **권고안**이며 확정된 데이터셋을 만들지 않았다.

| 항목 | 권고 및 근거 | 남은 결정 |
|---|---|---|
| 네이티브 32×32 | 원래 픽셀 유지 | 배경만 통일할지 선택 |
| 16×16 | 정수 2배 nearest 또는 32 캔버스 중앙 배치 비교 | 물체 크기·픽셀 밀도가 달라 출처별 실험 |
| 24×24 | 32 캔버스 패딩 우선 검토 | 비정수 확대는 픽셀 폭이 달라짐 |
| 기존 34×34 | 전체 nearest 축소와 물체 bbox 기반 무손실 배치 비교 | 149개가 원본 외곽에 닿아 일괄 1픽셀 crop 금지 |
| RGB | 단순하고 초기 구현과 호환 | 배경색 학습·추론 후 투명화는 별도 문제 |
| RGBA | 투명도를 직접 학습할 수 있음 | 보이지 않는 RGB 0 처리, 알파와 색 손실·내보내기 검증 필요 |
| 정규화 | 선택한 채널을 [0,255]→[-1,1] | RGB/RGBA 확정 후 적용 |
| 증강 | 우선 미적용을 비교 기준으로 권고 | 좌우 반전도 글자·상징·방향성을 검토; 색 변경·임의 회전은 기본 제외 |
| 라벨 | 파일명은 추정, 수동 검토한 대분류 후보 | 무기/방어구·장신구/소비/재료/도구·기타/스킬 등 통합안 검토 |
| 분리 | 중복·근접 변형을 같은 그룹으로 묶은 뒤 seed 42로 분리 | 클래스와 출처 분포를 함께 확인 |

기존 `prepare_dataset.py`는 RGB 배경 [24,24,24], 전체 nearest resize, 90:10 파일 단위 분리로 495개를 만들었던 **검토용 코드**다. 새 출처의 시트·애니메이션·라벨·변형 그룹을 자동 처리하지 않는다. 새 원본 전체에 그대로 실행하여 학습 데이터로 사용하면 안 된다. 기존 445/50 분리는 최종 split이 아니다.

## 설정과 GPU 검사

초기 후보: Adam, lr=0.0002, batch=32, FP32, T=1000, 최대 epoch=200. epoch·학습률·배치를 실제 데이터와 샘플 변화에 따라 조정한다. 200 epoch로 충분하거나 제출 기한까지 특정 품질을 달성한다고 가정하지 않는다. Python/NumPy/PyTorch 기본 seed는 42이다.

`scripts/probe_model.py` 실측: RTX 4070 Ti SUPER, PyTorch 2.11.0+cu128, RGB, batch 32, 파라미터 **4,668,739개**. 임의의 0 텐서에 잡음을 주입한 순전파·역전파 1회 0.471초, PyTorch 최대 allocated **385.12 MiB**, reserved **480 MiB**. 모든 gradient 유한, 파라미터 변경 없음. optimizer·실제 이미지·체크포인트를 사용하지 않았다. 검증용 파라미터 사본은 포함하며 Adam 상태·샘플링·데이터 IO는 제외한다. 이는 전체 학습 시간/VRAM 측정이 아니다. FP32 파라미터+gradient+Adam 2 moments만의 이론상 메모리는 71.24 MiB이며 전체 피크와 혼동하지 않는다. 초기 batch32의 메모리 여유는 확인했지만 배치 확대의 품질 효과는 미검증이다.

## 학습 전에 남은 구현

1. 데이터 범위·변형 그룹·최종 split 확정 후 데이터로더와 전처리 갱신.
2. RGB/RGBA 및 클래스 조건 여부 선택; 강의 자료와 세부 블록 대조.
3. 과제 원문에 맞춰 0 epoch와 매 epoch의 고정 seed 샘플 저장. 현재 코드는 10 epoch마다 저장하고 0 epoch는 저장하지 않는다.
4. 학습 시간·검증 시간·샘플링 시간 및 전체 누적 실행 시간을 분리 기록. 현재 `train_seconds`와 호출별 시간만 있음.
5. 중단/재개, checkpoint, loss CSV, PNG 저장의 통합 테스트. 현재 loader는 root seed 42에 epoch offset을 더해 shuffle하므로 엄격한 seed 42 고정 정책과 함께 정리.
6. 실제 학습 후 train/val loss, 고정 잡음 샘플, 학습 이미지 최근접 비교와 다양성 검토. 과적합과 단순 암기를 확인하기 전 품질을 주장하지 않음.
