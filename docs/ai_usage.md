# AI 도구 활용 기록 초안

도구: OpenAI Codex. 작업일: 2026-11-18.

| 범위 | 실제 보조 내용 | 현재 검증 수준 |
|---|---|---|
| 데이터 검사 | PNG 수·해상도·채널·알파·중복·손상 검사, 미리보기와 통계 스크립트 작성 | 로컬 파일 검사 및 표본 시각 검토 |
| 수집 조사 | 공개 출처·다운로드 주소·라이선스 확인, 원본 ZIP/이미지 수집, 출처별 메타데이터 | 개별 이미지의 권리·라벨 검토는 일부 미완료 |
| 전처리 | 496 원본의 중복 제거·RGB/resize 검토용 코드와 비교 이미지 | 495개 임시 결과 검사; 최종 학습 전처리 아님 |
| 모델 | U-Net, DDPM, 데이터로더, 학습·샘플·재개 코드 초안 작성 | 수식/shape 단위 테스트와 임의 텐서 GPU 검사; 본 학습 미실행 |
| 문서 | 과제 PDF 요구사항 대조, 설계·검사·출처·남은 작업 정리 | 사용자가 설계 판단과 결과 해석을 검토할 자료 |

합성 데이터 4종 각 128장은 초기에 조사한 표본이다. 후속 결정으로 Pixel-art 172K와 Krea 16의 256개 표본은 학습 후보로 재검토하며, PixelGPT와 Atlas 표본 이미지는 삭제했다. PixelGPT는 사용자가 이미지 품질을 이유로 제외했다. 어느 자료도 모델 학습에 사용하지 않았다. AI 이미지 생성 도구로 학습용 에셋을 제작하지 않았다.

최종 보고서는 이 기록을 그대로 제출하는 완성본이 아니다. 사용자가 실제로 채택한 설계, 직접 검토·수정한 코드, 실제 실험과 분석을 반영하여 AI 활용 범위를 갱신한다. 완료하지 않은 실험이나 개인의 이해를 완료한 것으로 적지 않는다.
